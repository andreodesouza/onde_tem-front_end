# 📍 Onde Tem?

**Aplicativo Multiplataforma para Agendamento de Serviços Estéticos com Geolocalização**

Desenvolvido no curso de Engenharia de Software da **Universidade de Vassouras – Campus Saquarema**.

---

## 📖 Sobre o Projeto

O **Onde Tem?** é uma aplicação voltada para a cidade de Saquarema/RJ, criada para digitalizar e otimizar o agendamento de horários no setor de estética (salões de beleza, barbearias e clínicas). 

A plataforma substitui marcações informais por um sistema prático que conecta clientes e profissionais da região através de geolocalização e agendamentos em tempo real.

---

## 🎯 Principais Objetivos

- **Para os clientes:** Facilidade para encontrar estabelecimentos próximos e agendar serviços estéticos online.
- **Para os estabelecimentos:** Organização operacional, redução de faltas/cancelamentos e otimização da gestão.
- **Para o comércio local:** Incentivo aos negócios de Saquarema e inclusão tecnológica no setor.

---

## 🛠️ Tecnologias

- **Frontend:** HTML5, CSS3 e JavaScript
- **BanckEnd:** Django
- **Recursos:** Geolocalização
